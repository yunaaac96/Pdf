案例二：平台經營策略 (蝦皮 x YAHOO)

流量引擎 vs 穩定毛利角色定位優化

WHY 雙平台日流行為迥異，齊頭式定價導致轉換低或品牌信任感流失。
HOW 重新定義角色：蝦皮為流量與銷售引擎；Yahoo 為穩定利潤與品牌窗口。

案例三：優化與復盤

針對轉換率不佳進行即時修正

HOW：即時更換主打品為季節性新品，下修回饋門檻，素材改以實際使用情境呈現。
RESULT：ROAS 提升 +6，轉換率成功回升，建立活動中期優化 SOP。

Data Tools Logic

毛利計算表邏輯 活動價 → 成本分析、運費 + 贈品 → 總成本、淨利率 = 最終評估。
回饋試算邏輯 門檻設定 → 命中率分析、回饋形式 → 成本評估、最優方案 = 決測依據。
